# Contributing to Tilden

Tilden is a protocol-first project. Contributions should preserve implementation neutrality, federation, portability, and testability.

## Design principles

1. Do not require a single provider, registry operator, or runtime implementation.
2. Keep resolution semantics separate from call/session implementation.
3. Make trust, authority, expiry, and fallback explicit.
4. Prefer machine-readable schemas and executable conformance cases.
5. Preserve legacy telephone interoperability without making E.164 the only identity model.

Normative changes should include or update conformance examples where practical.
