# Schemas

Machine-readable schemas for Tilden resolution objects and related protocol structures live here.

- [`tilden-resolution-v1.schema.json`](tilden-resolution-v1.schema.json) — JSON Schema for the Tilden v1 Resolution Object defined by `TILDEN-CORE-001`
- [`tilden-authority-delegation-v1.schema.json`](tilden-authority-delegation-v1.schema.json) — JSON Schema for the Tilden v1 Authority Delegation Object defined by `TILDEN-AUTH-003`

Reference examples live in [`../examples/`](../examples/).
