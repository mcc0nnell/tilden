# Security Policy

Tilden specifications and reference code may influence identity resolution, routing, trust, and privacy for accessible real-time communications.

Please avoid publishing exploitable security details in public issues before maintainers have had a reasonable opportunity to assess them. Reports should include affected component/specification section, impact, reproduction details, and any proposed mitigation.

Security design for Tilden must assume hostile federation boundaries, stale or malicious records, downgrade attempts, replay, endpoint impersonation, and privacy-sensitive capability metadata.
